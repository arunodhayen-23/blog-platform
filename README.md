# Marginalia — A Blog Platform

A small full-stack blog platform with authentication, posts, comments, and a clean responsive UI.

## Features

- User registration and sign-in
- JWT-based authentication
- Create, edit, and delete your own posts
- Read posts and comments without signing in
- Add and delete your own comments
- Responsive single-page frontend
- Lightweight JSON database using lowdb

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

Set `JWT_SECRET` in production to a strong secret.
